# Arduino Night Lamp

Automatic night lamp simulated in Tinkercad.

Parts: Arduino Uno, LDR, 10k resistor, 220 ohm resistor, LED.

How it works: the LDR and 10k resistor form a voltage divider
read on pin A0. When the reading drops below 300, the LED on
